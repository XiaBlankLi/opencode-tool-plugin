# 使用手册

## 打开面板

- 方式一：命令面板（`Ctrl+Shift+P`）执行 **`OpenCode工具插件：打开侧栏`**
- 方式二：打开任意 `opencode` 终端页签，面板会自动出现

布局：面板固定在最右一列；点击历史会话后，opencode 以**编辑器页签**形式开在面板左侧一列，即 `文件 | opencode | 面板`。插件不会移动或重建你已有的页签。

## 面板区域

### 1. 动画区
- 顶部轮播显示 `media/` 下的动画 GIF
- 点击 **prev / next** 切换动画

### 2. 媒体播放器
- **音乐来源**：面板顶部提供来源切换
  - **本地 media**：播放 `media/` 目录下的音频文件（`.mp3`/`.wav`）
  - **网易云歌单**：播放登录后的网易云歌单；点击「网易云歌单」即展开网易云面板，切回「本地 media」自动收起
  - 来源互斥：使用本地时「网易云歌单」按钮置灰；使用网易云时「本地 media」按钮置灰
  - 网易云模式下自动隐藏切歌/轮播控件（◀ ▶ 自动轮播），图片区保留并正常显示网易云专辑封面与歌名
- **播放 / 暂停**：点击播放按钮
- **下一首**：点击切歌按钮
- **进度条**：显示播放进度，可拖动控制播放位置；进度条按当前歌曲时长自动缩放对齐

### 2.5 可用模型列表与状态栏
- **会话状态栏**（可折叠）：显示当前对话、Context tokens、用量百分比、花费、LSP 状态、当前 model 与 agent，每 5 秒自动刷新；点击标题栏可折叠/展开
- **可用模型列表**（可折叠，默认收起）：展示当前环境全部可用模型
- 每个模型行标注其能力图标：**PDF / 图片 / 视频**（亮起表示支持，灰暗表示不支持）；显示各模型上下文窗口大小

### 3. 会话状态区
实时显示 opencode 当前会话信息，每 5 秒自动刷新：

| 字段 | 说明 |
| --- | --- |
| 模型 | 当前使用的模型 |
| Agent | 当前 Agent |
| Context tokens | 上下文占用 token 数 |
| 用量百分比 | 上下文用量进度条 |
| 花费 | 累计费用 |
| LSP 状态 | Language Server 状态 |

### 4. 历史对话
- 列出最近的历史会话（按时间排序）
- 点击任意会话 → 以 `opencode` 终端页签形式恢复该会话：
  - 每次点击**新开一个** opencode 页签并恢复到对应会话
  - 会话跨端恢复：即使在其他终端/机器上开始的会话，也能从此处接续
- **重命名**：悬停会话行，点「重命名」→ 输入新标题（写入会话数据库）
- **删除**：悬停会话行，点「删除」→ 再次点击确认后删除该会话
- **查看全文**：点击会话旁的查看按钮，按需加载该会话的完整对话文本

### 5. 关键内容提取
- 选中某条历史会话后点击 **关键内容**，插件会用 `opencode run` 对会话内容做摘要：
  - 生成核心要点（有条理分点）+ 关键词
  - 全程使用临时会话，提取完成后自动删除，不占用你的会话列表
- **应用方法**：点击某条要点 → 内容自动复制到剪贴板，并填入 opencode 输入框（回车即发出）

### 6. 用户笔记
- 面板底部 **笔记** 区域可记录文字，点击保存即持久化
- 数据保存在 `~/.opencode-tool-notes.json`，重启后仍在

### 7. 网易云音乐
- 面板 **网易云** 标签提供：
  - **扫码登录**：展示二维码，手机网易云 App 扫码确认
  - **手机号登录**：输入手机号 + 短信验证码登录
  - **歌单**：登录后加载「我创建的歌单」，点击查看歌曲列表
  - **播放**：点击歌曲直接在线播放（播放器区同步显示）
  - **退出登录**：一键登出（本机 cookie 保存于插件目录 `.ncm-cookie.txt`）
- 前置条件：插件目录下需安装依赖，见 `docs/INSTALL.md`

## 环境变量

| 变量 | 说明 |
| --- | --- |
| `OPENCODE_EXE` | 可选。opencode 可执行文件完整路径；未设置时按 `PATH`、npm 全局目录顺序自动查找 |

设置示例（PowerShell）：

```powershell
[Environment]::SetEnvironmentVariable("OPENCODE_EXE", "C:\path\to\opencode.exe", "User")
# 修改后需重启 VS Code 生效
```

## 自定义

- **更换动画**：将 GIF 放入 `media/` 目录并刷新面板
- **更换音频**：将 `.mp3`/`.wav` 放入 `media/` 目录并刷新面板（注意版权）
- **更换图标**：替换 `media/icon.svg`

## 常见问题

| 问题 | 处理 |
| --- | --- |
| 面板不出现 | 执行命令 `OpenCode工具插件：打开侧栏`；或 Reload Window |
| 恢复会话无反应 | 确认已安装 opencode CLI，且 `OPENCODE_EXE`/`PATH` 指向正确 |
| 页签布局错乱 | `Ctrl+Shift+P` → `View: Reset View Locations` → Reload Window |
